# Text-to-speech generation

Call `generate_speech` for narration, dialogue, announcements, accessibility audio, or other spoken rendering. Pass only the text that should be spoken and preserve the requested language, voice, speakers, pace, emotion, and tone. Do not use this skill for songs, instrumental music, ambience, or sound effects.
