# Text-to-image generation

Call `generate_image` for a request to create a new raster image from text when no image reference is attached. Preserve the user's requested subject, composition, medium, lighting, palette, resolution or aspect ratio, and exclusions. Do not invent a fixed size: use an explicitly requested geometry or let the selected model choose a suitable default. Wait for the tool result and never fabricate a URL or claim generation succeeded early.
