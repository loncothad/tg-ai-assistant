# Image-to-3D generation

Call `generate_3d` to reconstruct or derive a 3D artifact from an attached or replied-to image. The backend supplies the reference. Preserve visible shape, proportions, materials, colors, and identifying details, and mention unseen geometry only as an inference. The backend delivers the resulting artifact as a Telegram file.
