# Text-to-audio generation

Call `generate_music` for songs, instrumental music, loops, ambience, sound effects, or other non-speech audio generated from text. Preserve the requested lyrics, musical style, instruments, mood, structure, duration, and language. If an authorized compound workflow first creates lyrics or a script, pass that completed text—not the instruction to write it—into the tool. Do not use this skill for ordinary narration.
