# Video understanding

Inspect only supplied Telegram video attachments when the user asks for a description, timeline, summary, scene analysis, visual question answering, or classification. Distinguish observed events from inference and state format or visibility limitations. Use transcription for exact spoken or sung words. Never use this skill for a YouTube URL; YouTube requests use the separate captions-only skill.
